4. Generate only specific pages (one or more features)
url# One single page (feature with id = 7)
&REPORT=My Districts Report
&FORMAT=pdf
&atlas_pk=7

# Several pages
&atlas_pk=3;7;12

# All pages (same as no atlas_pk parameter)
&atlas_pk=*
5. Quick curl one-liner to download the full report
Bash
curl -o districts_report.pdf \
  "http://localhost:3020/?SERVICE=WMS&REQUEST=GetProjectReport\
  &MAP=/projects/neogis-map.qgs\
  &REPORT=my-report\
  &FORMAT=pdf"
